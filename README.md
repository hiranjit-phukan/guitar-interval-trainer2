# 🎸 Guitar Interval Trainer

A browser-based guitar interval learning and fretboard practice app.

## Features

- Learn interval theory
- Fretboard Explorer
- Game 1 — Name the Note
- Game 2 — Find All
- Standard tuning: E A D G B E
- High E displayed at the top
- Responsive fretboard
- Fretboard zoom controls
- Horizontal scrolling when zoomed
- Touch-friendly note selection

## Run locally

Open `index.html` with VS Code Live Server.

## Publish

This project is designed to work directly with GitHub Pages.

After uploading the project to a GitHub repository:

1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select the `main` branch and `/ (root)`
4. Save

Your site will be available at:

`https://YOUR-USERNAME.github.io/guitar-interval-trainer/`
